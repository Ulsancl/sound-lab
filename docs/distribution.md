# 배포 범위와 확인 기준

이 문서는 Sound Lab 1.0의 유한한 기능 범위와 배포 확인 기준입니다. 실제 통과·설치·공개 상태는 각 버전의 결과 기록을 따릅니다. 최종 후보의 검증과 공개 파일 대조가 끝나기 전에는 배포 완료로 판단하지 않습니다. 개발자에 의한 앱 검사는 실제 사용자 연구·판매·유료 지원 검증을 뜻하지 않습니다.

`npm run package:desktop`은 `release/windows/Sound-Lab-Setup-1.0.0.exe`와 같은 이름의 `.sha256`을 만듭니다. 버전은 package.json을 따르며 자동 공개하지 않습니다. 설치 앱은 실행에 필요한 화면·모형·라이브러리를 로컬에 포함합니다. 코드 서명과 자동 업데이트는 제공하지 않습니다. 실험을 저장하고 앱을 닫은 뒤 새 설치 파일로 수동 업데이트합니다. 제거 설정은 사용자 앱 데이터를 자동 삭제하지 않도록 구성하며 이 설정 확인을 실제 제거 실행 검사와 혼동하지 않습니다.

배포 전에는 모형의 주파수·마디·부호 관계, 엄격한 파일 왕복과 원문 보호, 실제 세 안내 실험·구조 관찰·비교 축, 위상 정지와 오디오 중단을 확인합니다. 조건을 바꿀 때 조작 옆의 실제 Hz와 고조파 배수를 함께 읽을 수 있어야 합니다. 소스·패키지·실제 설치 앱의 네이티브 메뉴·파일·재시작은 실행 대상을 구분해 기록합니다. 소스와 ASAR·문서·라이선스 고지·설치 파일의 해시를 대조하고, 보존한 구버전의 입력·시점·원문을 새 버전이 그대로 복원하는지 확인합니다.

Windows CI는 순수 검사, 브라우저 조작, 소비자 관찰, 소스 네이티브, 패키징과 패키지 네이티브를 순차 실행합니다. 로컬 실제 설치·구버전 업데이트, 원격 CI, 공개 저장소·태그·다운로드 파일의 검증은 별도 결과입니다. 어느 하나의 성공을 다른 단계의 성공으로 대신하지 않습니다.

Web Audio의 오프라인 표본 검사는 발진 주파수·길이·gain을 확인할 수 있지만 사람의 실제 청취, 스피커 음량·음질·dB 측정의 증거가 아닙니다. 오디오 실패는 수치·화면 관찰을 막지 않아야 합니다. 로컬 하드웨어 근거는 기록된 Windows 11 x64·RTX 5080·150% 배율과 실제 검사한 창 크기에 한정합니다. CI의 가상 그래픽 장치 결과를 실제 GPU·모든 기기·원격 데스크톱·다른 운영체제까지 확대하지 않습니다.

관의 길이·경계·모드 선택은 새로운 고유모드를 고르는 조작입니다. 모드 사이 과도응답, 공명 폭·Q·감쇠, 끝단 보정·실제 음압·음향 안전을 계산한 것으로 설명하지 않습니다. 상대 압력 색과 가시화한 입자 왕복은 실측 자료가 아닙니다.
