# Windows 앱과 파일

Sound Lab의 대상은 Windows 11 x64입니다. [릴리스](https://github.com/Ulsancl/sound-lab/releases/latest)의 `Sound-Lab-Setup-1.0.0.exe`와 같은 버전의 `.sha256` 파일을 사용합니다. 실제 화면·하드웨어·설치·업데이트 결과는 해당 릴리스 기록을 따릅니다.

설치 파일을 열어 현재 사용자용 설치를 마친 뒤 바탕화면이나 시작 메뉴의 Sound Lab 아이콘으로 시작합니다. Node.js와 개발 서버 없이 로컬로 실행합니다. 코드 서명을 제공하지 않으므로 Windows가 게시자를 확인하지 못했다는 안내를 표시할 수 있습니다. 릴리스 출처와 파일 SHA-256을 확인하고 설치 여부를 결정하세요.

업데이트는 실험을 파일로 보관하고 앱을 닫은 뒤 새 설치 파일로 수동 진행합니다. 자동 업데이트 서비스는 없습니다. 제거 설정은 사용자 프로필을 자동 삭제하지 않도록 구성되어 있습니다. 제거 항목의 존재나 이 설정의 확인을 실제 제거 실행 검사로 주장하지 않습니다.

Ctrl+N/O/S는 새 실험/열기/저장, Ctrl+Shift+P는 느린 **위상 재생 / 일시정지**, Ctrl+Shift+F는 3D 크게 보기, F1은 사용 안내입니다. 파일 작업은 위상 재생과 소리를 멈추며 취소해도 자동 재생하지 않습니다. 음높이는 명시적으로 화면 버튼을 눌러 들으며 위상 재생과 별개입니다.

파일은 현재 조건·위상·탐침과 비교 한 개, 관찰 표시와 카메라를 보관합니다. 정상 파일은 입력값을 그대로 복원하고 정지·무음으로 시작합니다. 형식과 원문 보호 범위는 [저장과 복원](storage.md)을 참고하세요.

잘못된 필드·범위·미래 버전과 10 MiB 초과 파일은 보정하지 않고 거부합니다. UTF-8 BOM 한 개를 허용합니다. 손상되거나 미래 버전인 자동 저장 원문은 원키를 덮어쓰지 않고 별도 내보내기로 보관합니다. 자동 저장은 파일 백업을 대신하지 않습니다.

네이티브 저장은 같은 폴더의 임시 파일을 쓰고 동기화·닫기 후 교체합니다. 일시적인 Windows 공유 오류는 제한된 횟수로 재시도하며 매번 대상 경로를 다시 확인합니다. 기존 목적지를 먼저 지우지 않습니다. 파일 작업 중 창을 닫으면 종료 확인을 표시합니다. 전원 차단·저장 장치 고장까지 복구를 보증하지는 않습니다.

앱 신원은 `com.soundlab.app`, 화면은 `app://sound/`, 자동 저장 키는 `sound-lab-project-v1`입니다. 도움말의 저장 폴더 열기로 로컬 프로필에 접근합니다. 브라우저와 설치 앱의 자동 저장은 별개입니다. 개발 검사는 `SOUND_LAB_DATA_DIR`로 격리 프로필, `SOUND_DESKTOP_EXE`로 검사할 독립 실행 파일의 절대 경로를 지정합니다. 일반 사용에 필요한 설정은 아닙니다.
