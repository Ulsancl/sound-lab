# 관찰하는 구조

Sound Lab은 금속 실험대에 놓인 균일 원통 관을 직접 살펴보는 가상 장치입니다. 관의 내경은 40 mm, 외경은 46 mm이며 길이는 0.30–1.20 m에서 선택합니다. 길이를 바꾸면 내경이 다른 망원 관으로 늘어나는 대신, 같은 단면을 가진 다른 길이의 관과 그에 맞는 지지 위치로 바뀝니다.

## 실제 구조와 가상 표식

| 부품 | 관찰할 내용 |
| --- | --- |
| 실험대·레일·두 지지대 | 관과 관측 장치를 받치는 금속 구조입니다. 지지대와 고정 링은 관의 양끝에서 각각 55 mm 안쪽에 있습니다. 두 하중 레일이 지지대의 실제 관통 구멍과 중공 부시를 지나갑니다. |
| 원통 관·고정 링 | 속이 비어 있으며 내벽·외벽·고리 모양 끝면·절개면이 각각 존재합니다. 관은 도장된 막대가 아니라 두께 3 mm의 벽으로 표현됩니다. |
| 탈착 끝마개·보관대 | 닫힌 마개의 안쪽 면은 관의 왼쪽 끝과 맞닿습니다. 열면 관에서 떼어 별도 받침에 보관합니다. 오른쪽 끝은 항상 열려 있습니다. |
| 길이 눈금 | 왼쪽 끝 0부터 오른쪽 끝 L까지의 실제 관 길이를 m로 보여 줍니다. |
| 탐침 캐리지·연결선·표시 장치 | 탐침은 뒤쪽 독립 가이드를 따라 움직여 고정 지지대와 겹치지 않습니다. 이동 캐리지의 표식 위치가 가상 탐침의 위치입니다. 표시 장치는 계산한 Hz와 x/L, 상대 압력을 보여 줍니다. |
| 가상 압력 탐침 | 관을 방해하지 않는 이상적 측정점입니다. 얇은 표시선은 관 벽을 뚫는 실제 구멍이나 마이크 부하를 뜻하지 않습니다. |
| 공기 운동 표식 | 관 축 방향의 왕복을 확대해 보여 주는 점들입니다. 실제 공기 분자의 크기, 입자 간격 또는 이동거리를 나타내지 않습니다. |

관 안 좌표는 왼쪽 `x=0`, 오른쪽 `x=L`입니다. 관 중심 높이는 0.15 m이며 화면 속 세계 좌표는 `worldX=x−L/2`를 씁니다. 탐침은 평형 위치를 가리키고 공기 표식은 그 주위에서만 움직입니다. 열린 끝의 표식은 관 밖으로 조금 나갔다 돌아올 수 있습니다. 막힌 끝의 운동은 0입니다.

## 절개·분해·색을 읽는 방법

절개는 앞쪽 벽의 일부를 숨겨 내부를 관찰하는 표시입니다. 실제 관에 옆 구멍을 만든 경계조건으로 계산하지 않습니다. 분해 보기는 관·고정 링·끝마개 사이에 관찰 간격을 더합니다. 모델의 길이·경계조건·주파수와 탐침의 평형 위치는 그대로입니다. 조립 모습에서는 금속 벽이 내부 표식을 가릴 수 있으므로 내부를 보려면 절개를 사용하세요.

관 내부의 얇은 색 띠와 공기 표식의 색은 **대기압 대비 상대 압력**입니다. 파랑 −1, 밝은 회색 0, 주황 +1의 고정 척도를 사용합니다. 0은 대기압 자체가 0이라는 뜻이 아닙니다. 색 띠는 압력의 가상 표시이며 고체 삽입물이나 액체가 아닙니다. 색을 끄면 공기 표식은 일정한 색으로 남습니다.

청록색 고리는 **압력 마디**, 금색 고리는 **공기 변위·속도의 마디**를 나타내는 가상 표식입니다. 마디는 한 장면에서 우연히 0이 된 모든 점이 아니라 공간 진폭이 항상 0인 위치입니다. 따라서 위상에 따라 고리 위치가 흘러가거나 갑자기 늘지 않습니다. 입자는 위아래로 흔들리지 않으며, 종방향 운동과 별도 압력 그래프를 구별해서 보세요.

모델이 제공한 동일한 평형 위치와 위상의 상대 압력·변위가 색 띠, 점의 위치, 탐침 값에 사용됩니다. 화면에서 보이도록 점의 변위는 관 길이의 1%를 최대 크기로 확대합니다. 이 확대율을 실제 입자 변위로 해석하지 않습니다. 실제 Hz와 느린 관찰의 재생 속도는 별도입니다.

## 관찰 조작과 범위

부품을 선택하거나 창 크기를 바꿔도 카메라와 실험 조건은 유지됩니다. `전체 보기` 또는 명시적인 부품 집중 조작만 시점을 맞춥니다. 이름표는 화면에 고정된 글자와 연결점으로 부품을 가리킵니다. 작은 화면이나 집중 보기에서는 이름표 수를 줄이고 선택 부품을 우선 표시합니다.

`내부 구조 자세히`는 레일·관·고정 링·두 지지대·끝마개·탐침 캐리지의 가까운 관찰을 제공합니다. 지지 링 아래에는 외주에 맞는 오목한 받침이 있고, 끝마개에는 압착된 씰이 들어가는 환형 홈이 있습니다. 끝마개 상세 관찰에서만 씰을 축 방향으로 3 mm 당겨 홈을 보여 줍니다. 이 임시 인출과 다른 관찰 표시를 음향 경계조건으로 계산하지 않습니다.

내부 관찰을 마치면 원래 카메라와 현재 표시 옵션을 적용합니다. 내부 관찰 중 저장해도 확대된 임시 시점 대신 원래 카메라가 기록됩니다. 길이·끝 조건을 변경하거나 새 파일을 열면 내부 관찰이 종료됩니다. 씰과 부시의 치수는 대표 형상의 간격이며 실제 제작·밀봉 성능을 검증한 공차가 아닙니다.

이 장치는 원본으로 만든 대표 구조입니다. 특정 제조사 장비의 도면, 조립 공차, 실제 마이크·스피커·관의 성능을 재현하지 않습니다. 모형은 이상적인 1차원 관의 첫 세 고유모드이며 끝단 보정, 감쇠, 관 벽 진동, 실제 음압과 마이크 부하를 계산하지 않습니다. [모형 설명](model.md)에 경계조건과 수치 범위가 있습니다.
