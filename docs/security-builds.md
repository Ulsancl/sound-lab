# 안전한 빌드와 검증 산출물

웹과 데스크톱의 Vite 빌드는 HTML·설정·정적 파일·소스·Three.js를 공통 검증 경로로 읽고 비공개 스테이징에서 번들링합니다. 데스크톱 패키지는 아이콘·문서·설치 설정도 검증된 사본을 사용합니다. 심볼릭 링크·정션·특수 파일은 거부합니다. 설치 파일과 체크섬은 검증을 마친 디렉터리로 함께 게시합니다.

브라우저·데스크톱 테스트는 새 임시 디렉터리에 기록하고 게시 전 새 트리와 기존 결과 경로를 검사합니다. 기본 사용자 프로필의 변경 검사는 메모리에서 수행하고 보고서에는 변경 여부와 항목 수만 기록합니다. POSIX는 스테이징에 소유자 권한을 적용하고 다른 사용자가 쓸 수 있는 산출물 부모를 거부합니다. Windows는 생성 시 스테이징 DACL을 실행 계정으로 제한합니다. Windows에서 최종 게시 경로의 상위 폴더는 신뢰할 수 있는 계정만 수정할 수 있도록 작업 공간 권한을 관리하세요.

루프백 개발 서버는 빌드·패키지·검사 결과 경로의 HTTP 접근을 제한합니다. CI는 npm 설치 훅을 끄고 esbuild 바이너리의 실행을 확인한 뒤 Electron과 Chromium 런타임을 명시적으로 설치합니다. 신뢰할 수 있는 체크아웃과 잠금 파일에서 빌드하세요.

일반 패키지의 Electron은 ASAR 무결성을 강제하며 Node 실행 모드·환경 옵션·CLI Inspector를 비활성화합니다. CI는 해당 실행 파일의 퓨즈, 시작과 종료, 서명 정책을 검증합니다. Playwright의 메인 프로세스 검사는 Inspector가 필요한 테스트 전용 패키지를 별도 경로에 생성해 실행합니다.
