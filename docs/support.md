# 문제 보고

[문제 보고](https://github.com/Ulsancl/sound-lab/issues/new/choose)에 앱 버전, Windows 버전, GPU와 화면 배율·해상도, 재현 순서와 기대/실제 결과를 적어 주세요. 길이·끝 경계·모드·위상·탐침 위치, 현재 관찰인지 보관한 비교인지도 필요합니다.

오디오 문제에는 음높이 버튼을 눌렀는지, 화면의 Hz, 오류 문구, 오디오 출력 장치의 종류를 알려 주세요. 관찰 재생은 음높이 듣기와 별개입니다. 실제 스피커 음량·dB·음향 안전 판정은 앱의 지원 범위 밖입니다.

손상되거나 더 새로운 버전인 파일은 원문을 별도로 보관하고 덮어쓰지 마세요. 공유 전에 비교 이름·파일 내용·개인 경로·진단 로그를 확인하세요. 전체 사용자 프로필을 올릴 필요는 없습니다. 문제 보고는 응답 시간·모든 기기 호환성·유료 유지보수 계약을 보장하지 않습니다.
