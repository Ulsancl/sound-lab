# Sound Lab의 정상파 모형

Sound Lab은 균일한 원통 관 안의 **이상적인 1차원 정상파**를 보여준다. 양끝이 열린 관과 왼쪽이 막힌 관의 첫 세 고유모드를 선택하고, 상대 압력과 공기 입자의 축방향 왕복을 비교한다. 계산은 해석식으로 수행하며 화면 프레임 수에 따라 변하는 수치 적분이나 과거 이력 재생이 필요하지 않다.

모형 버전은 `sound-standing-wave-1`이다. 실제 관의 음압, 음색, 방음 성능 또는 청취 위치별 소리 크기를 예측하지 않는다.

## 조건과 단위

| 항목 | 값·범위 | 의미 |
| --- | --- | --- |
| 음속 c | 343 m/s | 20°C 공기의 교육용 고정 근삿값 |
| 길이 L | 0.30–1.20 m, 기본 0.60 m | 관 안의 기하학적 길이 |
| 경계 | 양끝 열림 / 왼쪽 막힘·오른쪽 열림 | 열린 끝의 음향 압력 0, 막힌 끝의 입자 운동 0 |
| 모드 n | 1, 2, 3 | 낮은 주파수부터 세 번째까지의 허용 고유모드 |
| 탐침 위치 r | 0–1, 기본 0.5 | 평형 위치 x/L, 실제 좌표 x=rL |
| 관찰 위상 φ | 0 이상 2π 미만, 기본 0 | 한 주기 안에서 관찰할 순간, rad |

343 m/s는 공기 20°C에서 사용하는 대표 근삿값이다. 온도·습도 변화는 이 앱의 입력이 아니므로 음속도 바뀌지 않는다. [OpenStax, Speed of Sound](https://openstax.org/books/university-physics-volume-1/pages/17-2-speed-of-sound)

열린 끝의 ‘압력 0’은 **대기압 대비 압력 변동분**이 0이라는 뜻이다. 진공이라는 뜻이 아니다. 열린 관의 실제 반사 위치는 관 끝과 정확히 같지 않으며 관 밖 공기의 운동도 영향을 준다. 여기서는 끝단 보정을 제외한 이상적 경계를 사용한다. [UNSW Music Acoustics, Open vs Closed Pipes](https://phys.unsw.edu.au/jw/flutes.v.clarinets.html)

## 주파수와 파장

파수 k의 단위는 rad/m, 파장 λ는 m, 주파수 f는 Hz, 실제 주기 T는 s이다.

| 관 | k | λ | f | 기본음의 정수배 |
| --- | --- | --- | --- | --- |
| 양끝 열림 | nπ/L | 2L/n | nc/(2L) | n |
| 왼쪽 막힘 | (2n−1)π/(2L) | 4L/(2n−1) | (2n−1)c/(4L) | 2n−1 |

항상 `fλ=c`, `T=1/f`, `ω=2πf=ck`이다. 한쪽 막힌 관의 두 번째 모드는 기본음의 세 배인 **3차 고조파**이며, 기본음 다음의 첫 번째 상음이다. 모드 순서와 주파수의 정수배를 구분한다. [OpenStax, Normal Modes of a Standing Sound Wave](https://openstax.org/books/university-physics-volume-1/pages/17-4-normal-modes-of-a-standing-sound-wave)

| 길이 | 양끝 열림 1·2·3모드 | 왼쪽 막힘 1·2·3모드 |
| --- | --- | --- |
| 0.50 m | 343 / 686 / 1029 Hz | 171.5 / 514.5 / 857.5 Hz |
| 0.60 m | 285.833333 / 571.666667 / 857.5 Hz | 142.916667 / 428.75 / 714.583333 Hz |
| 1.00 m | 171.5 / 343 / 514.5 Hz | 85.75 / 257.25 / 428.75 Hz |

같은 경계·모드에서 길이를 두 배로 하면 주파수는 절반, 파장은 두 배다. 지원 범위의 최저 주파수는 약 71.458333 Hz, 최고는 1715 Hz이다. 관의 내경은 3D 구조 표현에 사용하며, 이 1D 이상관의 고유주파수 식에는 직접 들어가지 않는다.

## 상대 압력과 입자의 운동

관의 왼쪽에서 오른쪽을 양의 x 방향으로 정한다. 부호 있는 공간형상 P와 D는 다음과 같다.

| 관 | 압력형상 P(x) | 변위형상 D(x) |
| --- | --- | --- |
| 양끝 열림 | sin(kx) | cos(kx) |
| 왼쪽 막힘 | cos(kx) | −sin(kx) |

순간값은 `상대 압력=P cosφ`, `상대 변위=D cosφ`, `상대 속도=−D sinφ`이다. 정지된 진폭 포락선은 각각 `|P|`, `|D|`이며 항상 0–1이다. 순간 압력·변위·속도는 −1–1이다. 세 물리량은 각각 정규화했으므로 동일한 숫자를 같은 물리 단위로 비교하면 안 된다.

이 부호 선택은 선형 음향의 관계 `p=−ρc²∂ξ/∂x`, `u=∂ξ/∂t`, `ρ∂u/∂t=−∂p/∂x`와 일치한다. 실제 진폭을 기호로 도입하면 `ξ₀=p₀/(ρc²k)`, `u₀=p₀/(ρc)`일 때 `D′=−kP`, `P′=kD`가 세 관계를 만족한다. 앱은 이 진폭들을 실측하지 않으며 Pa, dB, 실제 입자 이동거리 또는 m/s를 표시값으로 주장하지 않는다.

압력과 입자 **속도**는 시간상 1/4주기 차이다. 압력과 변위는 공통 cos 위상을 가지며 그 위치의 P/D 부호에 따라 동상 또는 반대 위상이다. 마디에서 진폭이 0인 물리량의 시간 위상은 비교하지 않는다. 공기 입자는 관의 축을 따라 움직이며, 별도 그래프의 위아래 곡선은 공기가 횡방향으로 움직인다는 뜻이 아니다. [OpenStax, Sound Waves](https://openstax.org/books/university-physics-volume-1/pages/17-1-sound-waves)

## 마디는 한 순간의 영점이 아니다

압력 마디는 `P=0`, 변위·속도 마디는 `D=0`인 고정 위치다. `φ=π/2`에는 모든 위치의 순간 압력과 변위가 0이지만 모든 위치가 마디가 되는 것은 아니다. `φ=0`에는 순간 속도가 모두 0이어도 입자들이 한 주기 내내 정지하는 것은 아니다.

| 관·모드 | 압력 마디 x/L | 변위·속도 마디 x/L |
| --- | --- | --- |
| 열림 1 | 0, 1 | 1/2 |
| 열림 2 | 0, 1/2, 1 | 1/4, 3/4 |
| 열림 3 | 0, 1/3, 2/3, 1 | 1/6, 1/2, 5/6 |
| 왼쪽 막힘 1 | 1 | 0 |
| 왼쪽 막힘 2 | 1/3, 1 | 0, 2/3 |
| 왼쪽 막힘 3 | 1/5, 3/5, 1 | 0, 2/5, 4/5 |

좌표는 해석식으로 구하며 화면 표본에서 영점에 가까운 점을 찾는 방법을 쓰지 않는다. 알려진 정확한 사분주기 위치는 삼각함수의 미세한 반올림 잔차 대신 정확한 0 또는 ±1을 사용한다. 임의의 작은 값을 마디로 바꾸는 허용오차 판정은 없다.

## 화면의 느린 시간과 실제 Hz

화면 한 주기 2초는 관찰을 위한 느린 위상 진행이다. 실제 주파수나 주기를 바꾸지 않는다. 예를 들어 길이 0.50 m의 열린 관 첫 모드는 343 Hz이며 실제 주기는 약 2.915452 ms이다. 화면이 2초에 한 번 움직여도 음파 주기가 2초가 되지는 않는다.

입자의 보이는 왕복 거리는 확대된 설명용 표시이다. 화면 이동거리와 벽시계 시간을 나누어 실제 공기 속도로 해석하면 안 된다. 음높이 예시는 계산된 Hz의 순음을 따로 재생하는 기능이며 탐침 압력의 녹음이나 예측 음량이 아니다. 모델 자체에는 벽시계, 오디오, 재생 상태 또는 시간 이력이 없다.

## 개발 API와 입력 보호

`src/model.js`는 다음을 내보낸다.

```js
MODEL_VERSION
DEFAULT_CONFIG
DEFAULT_PHASE_RAD
DEFAULT_PROBE_RATIO
normalizeConfig(input)
assertConfig(config)
wrapPhase(phaseRad)
normalizeProbeRatio(input)
solveMode(config)
sampleAt(config, positionRatio, phaseRad)
getSnapshot(config, { phaseRad = 0, probeRatio = .5, sampleCount = 129 } = {})
```

`assertConfig`는 정확히 `{lengthM,boundary,mode}`인 일반 객체만 받는다. 숫자 문자열을 변환하지 않고, 누락·추가 키·지원하지 않는 값·비유한 수치를 거부한다. 검증 성공 시 입력 객체를 수정하지 않고 그대로 반환한다.

`normalizeConfig`는 현재 UI의 기본값 처리용이다. 유한 길이는 범위로 제한하고 나머지 잘못된 길이는 0.6 m, 지원하지 않는 boundary/mode는 양끝 열림/1모드로 정한다. 저장 파일은 이 함수로 잘못된 값을 고치지 않고 엄격히 검사해야 한다.

`sampleAt`은 위치 0–1과 정규 위상 `[0,2π)`를 요구하며 위상을 자동 보정하지 않는다. `getSnapshot`만 생략된 관찰 옵션에 기본값을 준다. 알 수 없는 옵션은 거부하며 표본 수는 정수 2–513이다. 엄격 입력의 위상·위치에서 `−0`도 거부한다. UI용 `wrapPhase`는 유한 위상을 정규 구간으로 감싸고 `−0`을 +0으로 바꾼다. `normalizeProbeRatio`는 유한 수를 0–1로 제한하고 비정상 입력은 0.5로 정한다.

`solveMode`는 분리된 config, harmonic, frequencyHz, wavelengthM, periodS, waveNumberRadPerM 및 `nodes.{pressureRatios,displacementRatios}`를 반환한다. 마디 배열 좌표의 단위는 x/L이다.

`sampleAt`의 표본 형식은 다음과 같다.

```js
{
  positionRatio, xM,
  pressureShape, displacementShape,
  pressureEnvelope, displacementEnvelope,
  pressureRelative, displacementRelative, velocityRelative
}
```

`getSnapshot`은 `solveMode` 결과에 phaseRad, probeRatio, probe, samples를 더한다. 균일 표본은 양 끝을 포함한다. probe는 표본 배열의 가장 가까운 점이 아니라 요청한 정확한 위치에서 별도로 계산한다. 모든 반환 객체·배열은 입력과 다른 호출의 결과에서 분리된다. 동일한 x/L과 위상의 정규화 형상은 길이를 바꿔도 동일하다.

## 검증과 범위

순수 검사는 별도로 고정한 주파수 표, SI 관계, 마디 좌표, 축방향 운동의 부호, 공간·시간 유한차분, 위상별 에너지 적분, 엄격 입력과 반환값 분리를 검사한다. 큰 표본도 매번 현재 조건에서 직접 평가하므로 누적 프레임 오차가 생기는 적분 이력이 없다. 모델 검사는 3D 화면이나 실제 청취 검사를 대신하지 않는다.

실물에서 중요한 끝단 보정, 방사, 점성·열 손실, 유동, 벽 진동, 탐침 부하와 임의 주파수 구동은 계산하지 않는다. 모드 변경은 다른 고유모드를 선택하는 동작이며 두 모드 사이의 실제 과도응답을 재현하지 않는다. 표시 관의 절개·분해는 관찰 편의 기능으로 경계조건을 바꾸지 않는다. 출처는 물리 관계의 확인에 사용했고 외부 교재 도판·문장·음원은 앱 자산에 포함하지 않는다.
