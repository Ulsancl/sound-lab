# 저장과 복원

파일 형식은 `sound-lab-project`, 스키마 1, 모형 `sound-standing-wave-1`입니다. `experiment`는 `{config,phaseRad,probeRatio}`이며 config에는 관 길이 `lengthM`, 경계 `boundary`, 모드 `mode`가 있습니다. 위상은 0 이상 2π 미만인 라디안, 탐침은 관 길이의 0–1 비율입니다.

파일에는 비교 이름과 별도 실험 한 개, 절개·공기 입자·압력색·분해·이름표 표시, 선택 부품과 카메라도 담습니다. 주파수·마디·파형은 보관한 입력에서 다시 계산합니다. **재생 중 여부·오디오·안내 진행·벽시계 이력은 저장하지 않으며 불러오기와 재시작은 정지·무음 상태입니다.**

현재만·보관만 표시하는 선택은 잠깐 살펴보기 위한 화면 상태입니다. 파일을 열면 둘을 함께 봅니다. 같은 파형이 겹친다고 비교 기록이 사라진 것은 아닙니다. 새 실험·불러오기 직전 관찰은 현재 실행 중 되돌리기로 복원할 수 있으며 되돌리기 기록은 파일에 포함하지 않습니다.

파일 파서는 잘못된 범위·카메라·알 수 없는 항목·버전을 보정하지 않고 거부합니다. 10 MiB를 넘는 파일은 열지 않으며 Windows UTF-8 BOM 한 개를 허용합니다. 실패한 열기는 현재 관찰과 원본 파일을 바꾸지 않습니다.

자동 저장 키는 `sound-lab-project-v1`입니다. 손상되거나 더 새로운 버전인 자동 저장 원문은 원래 키를 덮어쓰지 않고 원문 내려받기를 제공합니다. 이 상태의 새 관찰은 별도 실험 파일로 보관하세요. 브라우저와 설치 앱의 로컬 프로필은 별개이며 자동 저장은 외부 백업을 대신하지 않습니다.

설치 앱은 같은 폴더의 임시 파일을 쓰고 동기화·닫기를 마친 뒤 목적지 파일을 교체합니다. Windows의 일시적 공유 오류는 총 775 ms 대기를 포함해 최대 6회 교체를 시도하며 대상 경로를 매번 다시 확인합니다. 기존 목적지를 먼저 삭제하지 않고, 실패하면 자신이 만든 임시 파일만 정리합니다. 전원 차단·디스크 고장까지 복구를 보증하지는 않습니다.
